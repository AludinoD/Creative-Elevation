# Creative Elevation
> **Status Notice:** The main website is active; however, the booking system is currently closed.

Creative Elevation is a website designed to showcase the spaces and services offered by the company while allowing potential clients to book a space directly.

This project was developed as part of a university project and is also intended to serve as a functional website for Creative Elevation, helping the company present its offerings and make the booking process more convenient for customers.

## Booking System

The website was designed to use the **Calendly API** to handle bookings and allow users to schedule a space directly through the website.

The Calendly integration is currently inactive because the required API functionality is behind a paid Calendly plan. The booking functionality can be re-enabled once the appropriate Calendly subscription and API access are available.
